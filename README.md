One original one-line joke about office life, written for the make.fun
One-Line Office Joke Laugh-Off bounty.

## The entry

> I asked for a raise and got a standing desk — apparently I'm now vertically promoted.

85 characters, one line, 16 words. The joke turns a raise into a standing
desk and lands on "vertically promoted" — the punchline reframes the desk
itself as the promotion.

## How it runs

`main.py` (Python standard library only) copies the finished joke from
`entry.txt` into the output directory the grader provides
(`MAKEFUN_OUTPUT_DIR`, default `/output`) as `entry.txt`.

```sh
python3 main.py
```
